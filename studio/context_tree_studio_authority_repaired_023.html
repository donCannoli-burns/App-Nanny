Keyword classification rules and priority meanings

Language uses a preset list; “Not listed” stores your custom label and adds an Agent review flag. Type describes subject (security, image, video, machine learning, education, fun…). Use describes audience (consumer, developer, editor, unknown, experimental). Scope describes where the reference applies (full app, parser, source repo, inspiration). Priority 1 = local convenience / already on machine; 10 = hard-stop dependency: do not proceed if missing or unsafe. This is a planning constraint, not permission to execute.

Auto-tagging matches explicit phrases from the five project keyword fields against saved reference text. It adds recorded matches without changing your manual tags, and does not pretend to understand semantic relevance. No external lookups are made.

Privacy: avoid passwords, tokens, authenticated URLs or other secrets. These records are stored locally and included in portable exports.
